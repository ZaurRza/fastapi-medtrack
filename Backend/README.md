# Как запустить программу

В папке корневой (TimurApp) есть 2 файла названные run*app*\*, в зависимости от ОС выберите один из них

- _run_app_mac_linux.sh_ Создан для запуска на маке\линуксе. Чтобы запустить нужно перейти в папку проекта (то есть .../TimurApp) и написать в терминале chmod +x run_app_mac_linux.sh ,после этого нужно написать bash run_app_mac_linux.sh (или ./run_app_mac_linux.sh если не сработало. Если и это не сработало то чат гпт, сам скрипт рабочий). Проблема в том что в одной консоли откроется и терминал и сервер
- _run_app_windows.bat_ Создан для запуска на винде. Нужно перейти в папку проекта (то есть .../TimurApp) и открыть visual studio code и нажать правой кнопкой мыши на этот файл. Далее найти run code и нажать на него. Скрипт запустится и скачай все что нужно. Должно открыться 2 консоли с сервером и терминалом

# О программе

Программа разделена на две части:

## Сервер

- Сервер рабоает на опенсорс библиотеке _FastAPI_
- Весь функционал по идее должен быть реализован (возможны баги)
- Пароль юзеров хешируется библиотекой _bycript_
- Соедеинение с базой данной происходит благодаря _mysql.connector_
- Сервер проверяет время онлайна и заход (подробнее в ридми терминала)
- Сервер делает проверку на юзера и делит функционал на **админ (admin)** и **фармацевт (pharmacist)**
- Ответ сервер отправляет в формате {"статус","код","результат процесса"} и если все успешно то добавляет {"ответ сервера"}

## Терминал

- Терминал имеет свою валидацию (подробнее в ридми терминала)
- Терминал показывает только определенный функционал на основе роли юзера
- Чтобы войти в аккаунт требуется номер работника и его пароль
- Админ может создавать новые аккаунты на основе имеющихся работников и задавать им роли
- Работник может только зайти на аккаунт созданный админом

## База данных

- В папке терминал есть sql скрипт который создает базу данных, можно создать локально БД
- Сам БД удаленно захосшен, так что доступ есть с любого устройства и изменения также видны с любого устройства

### Странные файлы

_ca.pem_ это файл с сертификатом нужный для БД
_sysCaller.txt_ файл иммитации физического адреса устройства
другие файлы либо библиотеки, либо кеши, либо файлы после миграции
